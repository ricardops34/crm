# CanUseWebUI

> Fonte oficial: https://tdn.totvs.com/pages/releaseview.action?pageId=654955251

## Sintaxe

```text
CanUseWebUI() → lRet
```

## Retorno

lRet - Logical - Se verdadeiro, indica que o ambiente está apto a abrir um app via porta única utilizando a FWCallApp.
