# FwRetIdiom

> Fonte oficial: https://tdn.totvs.com/pages/releaseview.action?pageId=578814918

## ConteÃºdo

Descrição
Retorna o idioma ativo

Sintaxe
FwRetIdiom( ) → cRet

Retorno
cRet - Mnemônico do idioma ativo

Estes são os retornos possíveis e seus respectivos idiomas:
"pt-br" - Português do Brasil
"pt-pt" - Português de Portugal
"en" - Inglês
"es" - Espanhol
"ru" - Russo

Exemplo
ExpC1 := FwRetIdiom()
